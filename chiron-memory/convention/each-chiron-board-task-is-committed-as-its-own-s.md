Each Chiron board task is committed as its own standalone git commit, titled with the Spanish task name matching the board entry verbatim (e.g. "Tarea 4 — UI: mostrar la racha en la card")

## Why
confirmed by git log showing prior tareas (Tarea 3, TipWidget, Saludo widget, etc.) each as separate commits, and followed by committing this task's change alone rather than bundling with unrelated files

## Where
repo git history / commit workflow for src/app changes.
